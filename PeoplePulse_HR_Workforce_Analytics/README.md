# PeoplePulse | HR Workforce Analytics

## Project Overview
An HR analytics dashboard for exploring workforce composition, employee demographics, departments, education, job titles, salary and workforce movement.

## Tools & Technologies
Tableau Desktop / Tableau Public (where compatible)

## Dashboard Highlights
Workforce summary and detail dashboards; age and age groups; age vs education and salary; department, city and state views; education and performance analysis.

## How to Use
1. Download or clone this repository.
2. Open the workbook in the relevant desktop application.
3. If prompted, enable editing or allow the packaged data connection.
4. Explore the dashboard and its available filters.

## Notes
Packaged workbook and embedded data/assets are retained. Dashboard display names were updated; worksheets and source data were not redesigned.
