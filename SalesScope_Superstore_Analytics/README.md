# SalesScope | Superstore Performance Analytics

## Project Overview
A retail performance dashboard focused on sales, profit, quantity, regional performance, state-level results and monthly segment trends.

## Tools & Technologies
Tableau Desktop / Tableau Public (where compatible)

## Dashboard Highlights
Sales, profit and quantity KPI sheets; profit trend; monthly sales by segment; sales and profit by state; regional sales; average state sales and profit.

## How to Use
1. Download or clone this repository.
2. Open the workbook in the relevant desktop application.
3. If prompted, enable editing or allow the packaged data connection.
4. Explore the dashboard and its available filters.

## Notes
Packaged workbook and embedded data/assets are retained. Dashboard display names were updated; worksheets and source data were not redesigned.
