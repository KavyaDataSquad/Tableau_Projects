# LoanLens | Financial Loan Analytics

## Project Overview
 A financial loan analytics project examining loan applications, funded and received amounts, good-loan and bad-loan segments, interest rates and debt-to-income measures.

## Tools & Technologies
Tableau Desktop / Tableau Public (where compatible)

## Dashboard Highlights
Overview, summary and details dashboards; good vs bad loan applications; funded and received amounts; average interest; average DTI; employee length and loan-related breakdowns.

## How to Use
1. Download or clone this repository.
2. Open the workbook in the relevant desktop application.
3. If prompted, enable editing or allow the packaged data connection.
4. Explore the dashboard and its available filters.

## Notes
Packaged workbook and embedded data/assets are retained. Dashboard display names were updated; worksheets and source data were not redesigned.
