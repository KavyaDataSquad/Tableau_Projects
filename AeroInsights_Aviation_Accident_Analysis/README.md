# AeroInsights | Aviation Accident Analysis

## Project Overview
An aviation safety analytics project exploring accident patterns across airport locations, flight phases, purpose, year, aircraft damage and U.S. geography.

## Tools & Technologies
Tableau Desktop / Tableau Public (where compatible)

## Dashboard Highlights
Accident totals; accidents by airport location; phase-of-flight breakdown; purpose analysis; yearly accident trend; aircraft damage; U.S. accident categories and state-level views.

## How to Use
1. Download or clone this repository.
2. Open the workbook in the relevant desktop application.
3. If prompted, enable editing or allow the packaged data connection.
4. Explore the dashboard and its available filters.

## Notes
Packaged workbook and embedded data/assets are retained. Dashboard display names were updated; worksheets and source data were not redesigned.
